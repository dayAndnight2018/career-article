# 全14推进有机更新 促进城乡融合发展

城市建设，最终是为了让人民生活更美好。推进城市有机更新，壮大县域经济，打通城乡要素壁垒，促进城乡融合，是推进现代化的重要路径。

坚持有机更新，打造宜居活力社区。城市更新拒绝大拆大建，走 “留改拆” 有机更新路线。改造老旧小区，完善停车位、养老、便民设施，保留城市记忆。兼顾风貌保护和民生改善，让老城既有烟火气，又有新活力。

做强县域特色产业，激活县域经济引擎。县域是城乡连接的枢纽。立足资源禀赋发展特色产业，避免同质化竞争。临沂等省域副中心城市发挥辐射带动作用，带动周边县域产业升级，做强县城产业平台，吸纳就近就业，稳住县域经济基本盘。

打通要素通道，构建城乡互促格局。破除城乡要素流动壁垒，推动人才、资本、技术下乡。完善城乡基础设施一体化布局，推动教育、医疗等公共服务向乡村延伸，缩小城乡差距，形成以城带乡、城乡互补、融合共生的格局。

城乡融合，大势所趋。持续推进城市有机更新，做强县域经济，促进资源双向流动，走出一条城乡协同共进的现代化之路。
