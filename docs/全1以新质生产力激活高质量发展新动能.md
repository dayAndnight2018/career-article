# 全1以新质生产力激活高质量发展新动能

创新是引领发展的第一动力，新质生产力是高质量发展的核心引擎。当前，新一轮科技革命和产业变革加速演进，唯有紧紧抓住科技创新这个主线，培育壮大新质生产力，走好科技自立自强之路，才能在激烈竞争中塑造发展新优势。

坚持科技创新引领，筑牢新质生产力的技术根基。新质生产力，“新” 在科技创新，质在突破传统路径依赖。基础研究是科技创新的源头活水，要持续加大科研投入，支持高校、科研院所攻关关键核心技术，破解 “卡脖子” 难题。同时激发企业创新主体活力，鼓励企业建设研发平台，推动人工智能、算力、低空经济等前沿技术持续迭代，让原创成果不断涌现，为产业升级提供技术支撑。

推动产业迭代升级，拓展新质生产力的应用场景。科技创新不能停留在实验室，要落地到产业沃土之中。一方面推动传统制造业数字化、智能化改造，淘汰落后产能，让老产业焕发新生；另一方面培育战略性新兴产业，布局未来产业赛道。山东依托产业基础，大力发展智能制造、算力产业集群，推动新技术走进工厂、融入生活，让新产业、新业态、新模式成为经济增长的新支柱。

优化制度营商环境，厚植新质生产力的发展沃土。培育新质生产力，既要抓技术，也要优生态。完善知识产权保护制度，保障创新者合法权益；落实助企创新政策，简化审批流程，用好包容审慎监管，给新技术、新业态留出试错空间。持续完善人才引育机制，集聚高端科技人才，打通产学研转化通道，让创新要素自由流动、高效配置。

惟创新者进，惟创新者强，惟创新者胜。以科技创新开辟发展新赛道，以新质生产力塑造发展新优势，久久为功、持续发力，就能不断夯实高质量发展根基，稳步推进现代化建设。
