# 全12善用数据要素 统筹发展与安全

数据是新型生产要素，安全是数字发展的前提。数字时代，数据要素释放巨大经济价值，同时算法乱象、数据泄露、人工智能伦理风险相伴而生。用好数字红利，统筹发展和安全，引导数字经济向善发展。

激活数据要素，释放数字经济价值。加快数据要素市场化配置，推进数据确权、数据流通，挖掘政务数据、产业数据价值。推动大数据赋能工业、农业、服务业，培育数字产业新业态，让数据成为驱动增长的新引擎。

健全监管规则，守住数据安全底线。发展不能以牺牲安全为代价。完善数据安全、个人信息保护法律法规，规范平台收集、使用用户信息行为。严厉打击非法爬取、倒卖个人信息等违法行为，压实平台主体责任，筑牢数据安全防线。

坚持以人为本，引导 AI 向善发展。人工智能技术快速迭代，必须守住伦理底线。完善算法备案、AI 内容治理规则，防范算法歧视、深度伪造等风险。技术发展始终服务于人，不能反过来损害群众权益，让新技术服务民生、造福社会。

数字浪潮奔涌向前，安全底线不可逾越。善用数字之力，严守安全之门，平衡创新活力与监管规范，让数字经济行稳致远。
