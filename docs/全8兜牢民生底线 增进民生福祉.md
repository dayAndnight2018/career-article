# 全8兜牢民生底线 增进民生福祉

民生无小事，枝叶总关情。发展的最终目的，是为了人民幸福。兜牢民生底线，聚焦群众急难愁盼，扎实办好民生实事，持续增进民生福祉，是一切工作的出发点和落脚点。

坚持就业优先，稳住群众收入基本盘。就业是最大的民生。落实稳就业政策，拓宽高校毕业生、农民工、灵活就业人员就业渠道。扶持新业态就业，完善灵活就业社保政策，规范平台用工，保障劳动者权益。多渠道开发岗位，强化技能培训，帮助群众稳就业、增收入。

聚焦一老一小，补齐普惠公共服务短板。“一老一小” 是民生重点。持续推进居家适老化改造，发展社区养老、普惠养老；扩大普惠托育供给，缓解家庭育儿压力。完善社区养老托育站点，让老人安心养老、幼儿就近托育，减轻家庭养育养老负担。

完善医疗住房保障，回应群众现实期盼。持续深化基层医疗卫生改革，提升乡镇卫生院、社区卫生室服务能力，方便群众就近就医。健全保障性住房体系，支持刚需住房，规范商品房市场，减轻群众住房压力。从看病、住房等关键领域持续发力，不断补齐民生短板。

民生连着民心，民心凝聚民力。用心用情办好一桩桩民生实事，一件接着一件办，一年接着一年干，让发展成果更多更公平惠及全体人民，扎实推进共同富裕。
