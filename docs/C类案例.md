# C类案例

### 产业振兴・土特产、党支部领办合作社、片区联建

1. **兰陵代村（临沂）**｜`党支部领办合作社，土地流转，发展现代农业、乡村文旅，强村带动周边弱村抱团发展。村集体增收，带动村民稳定致富，打造乡村振兴样板`。

2. **沂水诸葛镇陌上花开片区（临沂）**｜`跨村联建，党支部领办合作社，盘活闲置宅基地、废弃坑塘等沉睡资源，发展特色种养和乡村文旅。闲置资产转化为增收资本，实现片区共建共享`。

3. **沂南竹泉村（临沂）**｜`依托古村落资源，保留乡土风貌，发展民宿、研学、乡村文旅，村集体和村民按比例分红。守住乡愁，实现文旅富民`。

5. **蒙阴蜜桃（临沂）**｜`立足山地禀赋，打造地理标志农产品，对接电商直播、冷链物流，延伸销售链条。小果品做成大产业，拓宽果农增收渠道`。

### 基层治理・人居环境、议事协商、共建共治

3. **临沂村级乡贤调解工作室**｜`吸纳老党员、乡贤参与矛盾调解，板凳会、炕头谈，小事就地化解。实现小事不出村、矛盾不上交`。

5. **临沂村居人居环境整治**｜`整治前入户走访征集意见，保留古树、老街等乡土元素；落实门前三包、红黑榜长效管护。避免一刀切，兼顾颜值与乡`愁。

### 基层干部・担当奉献、为民初心

1. `王传喜（兰陵代村）｜临危受命接手负债乱村，数十年扎根乡村，苦干实干，靠集体经营带领村庄蝶变。心中装百姓，扎根乡土久久为功`。

2. **李伟民（2025C 卷原型）**｜放弃县城稳定岗位返乡，常态化入户走访，化解土地矛盾，发展合作社产业，推进人居环境 “三改一提”。扎根基层，办好群众身边小事。

3. **沂蒙基层干部群体**｜`传承沂蒙精神，坚持水乳交融、生死与共，常态化走访群众，把群众急难愁盼放在首位。厚植为民情怀，走好群众路线`。

### 乡风文明・文化两创、红白理事会、移风易俗

2. **临沂各村红白理事会**｜`完善村规民约，党员乡贤带头，推行简办婚事、厚养薄葬，抵制高价彩礼、大操大办。减轻群众负担，涵养文明乡风`

### 生态宜居（可搭配人居环境、乡村振兴）

1. **威海菱角湾片区**｜因地制宜发展特色苗木产业，同步做好生态保护，连片打造生态产业片区。生态保护与产业发展双向共赢。
