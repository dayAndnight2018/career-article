# C类金句

## 古文金句

> 一枝一叶总关情——为民小事，岗位价值
>
> 苔花如米小，也学牡丹开——平凡岗位
>
> 道虽迩，不行不至；事虽小，不为不成——实干
>
> 橘生淮南则为橘，橘生淮北则为枳——因地制宜，片区化
>
> 位卑未敢忘忧国——小岗位，大责任
>
> 衙斋卧听萧萧竹，疑是民间疾苦声——听民声、牵挂群众
>
> 纸上得来终觉浅，绝知此事要躬行——入户调研，反对形式主义
>
> 治国有常，而利民为本——治理的落脚点
>
> 锲而不舍，金石可镂——攻坚、长效管护
>
> 穷则变，变则通，通则久——改革破题，整治
>
> 士不可以不弘毅，任重而道远——青年干部，使命担当

## 四大主题政策表述

1. 乡村振兴齐鲁样板

打造乡村振兴齐鲁样板，是习近平总书记对山东的殷切嘱托  
健全`五级书记抓乡村振兴`责任体系，一级做给一级看  
选好一个人，往往就能搞活一个村

> 齐鲁样板不是一句口号，而是一份沉甸甸的政治责任。
>
> “些小吾曹州县吏，一枝一叶总关情。”乡镇干部职位不高，管的却是群众最具体的事：一条路、一口井、一次宅基地纠纷。兰陵代村的王传喜接手的是一个负债乱村，数十年扎根，靠的就是把每件“小事”都当“大事”办。

2. 片区化推进

“`分类有序、片区化推进乡村振兴`”已写入“十五五”规划建议  
每年规划建设片区 300 个左右，其中省级 70 个  
`分好类、排好队，抓一片成一片；大带小、强带弱，不搞一刀切`  
省情：5.4 万个行政村、3400 多万农村人口，村小、布局散、基础弱

> 片区化不是“撒胡椒面”，而是“攥指成拳"  
>
>
> “十五五”规划建议明确提出“分类有序、片区化推进乡村振兴”。橘生淮南则为橘，生于淮北则为枳，乡村振兴最忌千村一面。临朐寺头把小红果做成致富果，金乡鱼山把一头大蒜做出 30 项专利——同一省份、不同答案，发展的钥匙不在别人手里，而在自己的资源禀赋里。

3. 党支部领办合作社

发展新型农村集体经济，村党组织领办合作社  
健全联农带农机制，让农民分享产业增值收益  
党支部领办 + 农户入股 + 统一经营 + 按股分红

> 领的不只是产业，更是人心；群众不敢干时，党员先干。  
>
>
> 发展新型农村集体经济，关键在把组织优势转化为发展优势。沂水诸葛镇由党支部领办合作社，盘活闲置宅基地、废弃坑塘，让“沉睡资源”变成“活资本”。群众不敢干时党员先干，群众不会干时支部带头。

4. 共建共治共享

打造共建共治共享的社会治理格局  
建设人人有责、人人尽责、人人享有的社会治理共同体  
坚持新时代枫桥经验：小事不出村、大事不出镇、矛盾不上交

> 难点不在“改什么”，而在“怎么让群众愿意一起改”。  
>
>
> “治国有常，而利民为本。”建设人人有责、人人尽责、人人享有的社会治理共同体，重点不在制度上墙，而在群众上桌。湖西片区改造先开议事会、先讲补偿账，把群众从“要我改”请成“我要改”。
