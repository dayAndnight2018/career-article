# 全11立足当下谋长远 擘画现代化新蓝图

谋定而后动，知止而有得。中长期规划是国家发展的行动纲领。十五五规划编制推进之际，坚持系统观念，统筹当前与长远，把蓝图变成行动，方能稳步推进中国式现代化。

立足国情实际，保持发展战略定力。规划不是空中楼阁，必须扎根现实。认清发展阶段、机遇挑战，不脱离实际、不急于求成。立足我国发展基本面，稳住发展节奏，聚焦高质量发展主线，保持政策连续性，不被短期波动干扰长远方向。

坚持统筹兼顾，处理好当前与长远的辩证关系。发展之中处处有取舍，要兼顾短期民生诉求和长远发展布局。既要办好当下群众急难愁盼，又要布局科技攻关、生态保护、基础设施等利在长远的工程。摒弃短视政绩观，多做打基础、利长远的实事。

狠抓实干落实，把规划蓝图转化为现实成果。蓝图再好，不落实就是空谈。健全规划实施机制，分解任务、压实责任，定期评估调整。发扬钉钉子精神，一张蓝图绘到底，一茬接着一茬干，避免规划悬空、政策空转。

凡事预则立，不预则废。树立长远眼光，兼顾当下实效，以科学规划引领发展，以实干担当推动落实，稳步向着现代化目标不断迈进。
