# 2基层治理与安全底线

基层是国家治理的 “神经末梢”，治国安邦，重在基层。新时代枫桥经验告诉我们，矛盾最好化解在源头。如今数字化政务快速普及，但基层仍面临形式主义负担、老年群体数字鸿沟、矛盾纠纷化解压力。政之所兴在顺民心，政之所废在逆民心。做好基层治理，要坚持党建引领、数字赋能、源头化解，以精细化治理守护万家平安。

坚持党建引领，锚定基层治理 “主心骨”。党建引领是基层治理的根本保证。基层治理千头万绪，只有党组织靠前统筹，才能凝聚多方力量。社区、乡村党组织主动下沉，党员深入群众走访倾听，把群众诉求收集上来，把政策服务送到家门口。基层党员扎根一线，直面群众难题，才能打通政策落地的 “最后一公里”，凝聚共建共治合力。

善用数字赋能，兼顾效率与民生温度。数字变革为基层治理增效，但技术不能替代人文关怀。推进 “高效办成一件事” 改革，简化线上办事流程；同时保留线下窗口，做好适老化改造，不让老年人在数字时代掉队。**淄博搭建基层一网统管平台，群众诉求线上一键提交、部门闭环响应，实现民生问题快速处置。**数字工具是手段，为民服务才是目的，科技赋能应当有民生温度。

坚持源头化解，守住基层平安底线。小事不出村，大事不出镇，矛盾化解在基层。基层矛盾大多源自群众日常小事，若忽视苗头，小事极易演变为大问题。依靠多元调解队伍，柔性化解邻里、土地纠纷，常态化排查风险隐患。勿以恶小而为之，勿以善小而不为。及时回应群众诉求，才能从源头减少矛盾，筑牢社会安全的坚实防线。

治国有常，而利民为本。基层治理没有终点，只有连续不断的新起点。见贤思齐，持续优化治理方式，用心用情办好群众一件件小事，方能夯实社会根基，交出人民满意的基层治理答卷。
