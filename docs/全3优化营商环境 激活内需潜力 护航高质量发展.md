# 全3优化营商环境 激活内需潜力 护航高质量发展

营商环境就是生产力，市场活力就是发展动力。民营经济、个体工商户是市场主体的重要组成部分，扩大内需是长期发展的战略基点。持续优化营商环境，释放内需潜力，不断激发市场活力，是推动经济高质量发展的必然选择。

助企纾困赋能，呵护市场主体成长。市场主体是经济的力量载体。落实 “政策找人”，变 “企业找政策” 为 “政策找企业”，精准推送减税降费、补贴扶持等惠企政策。坚持包容审慎监管，杜绝 “一刀切” 式执法，对新业态、新模式给予容错空间，帮助小微企业、个体工商户解决融资难、经营难等痛点，稳住市场基本盘。

多措并举促消费，释放国内市场巨大潜力。内需是我国经济发展的基本动力。持续推进汽车、家电以旧换新，培育文旅、康养等服务消费，完善县域商业体系，补齐农村消费短板。不断规范消费市场秩序，保障消费者合法权益，营造放心消费环境，持续激发居民消费意愿，让内需市场持续升温。

深化改革破除壁垒，建设全国统一大市场。地方保护、市场分割是阻碍要素流动的堵点。持续推进市场化改革，落实公平竞争审查制度，破除隐性壁垒，保障各类市场主体平等使用要素、公平参与竞争。打通生产、分配、流通、消费各环节，让商品、要素自由流动，构建高效规范、公平竞争的国内统一大市场。

发展之路，活力为要。以暖心政策稳主体，以广阔内需促增长，以改革破局清障碍，持续优化营商环境，充分释放内需潜力，推动经济实现质的有效提升和量的合理增长。
