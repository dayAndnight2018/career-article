# 全7深入实施科教兴国 筑牢现代化人才根基

功以才成，业由才广。科技是第一生产力、人才是第一资源，创新是第一动力。深入实施科教兴国、人才强国战略，培育大批高素质人才，才能为高质量发展提供坚实支撑。

强化基础研究，夯实科技创新源头。基础研究是整个科学体系的源头。持续稳定支持基础学科研究，鼓励科研人员潜心攻关，宽容科研失败。引导高校、科研院所瞄准前沿方向，产出原创性科研成果，为技术突破提供源头供给，摆脱关键领域对外依赖。

深化产教融合，培育实用技能人才。产业发展需要大量技能型人才。大力发展职业教育，推动校企合作、订单式培养，对接产业需求设置专业，解决产教脱节问题。面向先进制造、数字产业，培养懂技术、能实操的产业工人，让教育供给匹配产业发展需求。

完善引才育才留才机制，营造良好人才生态。引才重在环境，留才重在诚意。完善人才评价体系，破除唯论文、唯学历的评价桎梏；落实住房、子女教育、科研经费等配套保障，吸引青年人才扎根。搭建干事创业平台，让人才有舞台、有回报、有归属感，持续释放人才红利。

千秋基业，人才为本。引才、育才、惜才、用才一体推进，持续完善科教人才体系，让源源不断的人才红利转化为发展动能，助力现代化建设行稳致远。
