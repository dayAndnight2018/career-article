# 3新质生产力

高质量发展是全面建设现代化国家的首要任务，新质生产力正是高质量发展的核心引擎。山东作为工业大省，正加快推动传统产业转型升级，培育新兴产业。与此同时，关键核心技术短板、产学研转化不畅、创新人才不足仍是制约瓶颈。穷则变，变则通，通则久。培育壮大新质生产力，要攻关核心技术、打通成果转化、厚植创新生态。

攻坚核心技术，突破创新发展 “卡脖子” 关卡。核心技术买不来、讨不来，自主创新是必由之路。新质生产力，根基在于原始创新。聚焦高端装备、新材料等重点领域，持续加大研发投入，支持科研团队潜心攻关。**烟台持续攻关海上风电装备核心技术，突破多项 “卡脖子” 难题，印证自主创新是产业升级的底气所在。**只有坚持自主研发，牢牢掌握核心技术，产业发展才有底气。

打通转化通道，让科技成果落地生金。科技创新不能止步于实验室，更要走向生产一线。不少科研成果锁在实验室，存在科研与产业脱节问题。要强化企业创新主体地位，搭建中试平台，促进产学研深度融合。山东依托制造业基础，推动新技术落地工厂，把技术变量转化为产业增量。畅通转化链条，才能让创新价值充分释放。

厚植创新生态，集聚科技创新人才。人才是创新的第一资源，发展新质生产力，关键在人。完善人才引育留用机制，健全创新评价体系，尊重科研规律，鼓励大胆探索。营造宽容失败的创新氛围，吸引高端人才、青年科研人员扎根齐鲁。聚天下英才而用之，才能持续为产业创新注入不竭动能。

创新之路道阻且长，行则将至。路漫漫其修远兮，吾将上下而求索。立足山东制造业优势，持续培育新质生产力，坚持科技自立自强，以创新驱动，推动全省经济迈上更高质量的台阶。
