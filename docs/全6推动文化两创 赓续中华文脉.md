# 全6推动文化两创 赓续中华文脉

中华优秀传统文化是中华民族的根和魂。推动中华优秀传统文化创造性转化、创新性发展，坚定文化自信，让古老文脉在新时代焕发新生，是文化建设的重要课题。

深挖文化根脉，做好传统文化保护传承。传承是创新的前提。系统梳理古籍、非遗、历史遗存，做好文物保护、非遗记录工作。山东依托尼山圣境，深挖儒家文化内涵，保护地方戏曲、手工技艺等非遗资源，守住文化家底。只有扎实做好保护，才能为创新转化打下坚实根基。

创新表达载体，推动传统文化融入现代生活。传统文化不能束之高阁，要贴近当代人的审美与生活。借助短视频、数字文博、国风文创等新形式，活化传统文化。用年轻人喜闻乐见的方式讲好传统故事，让文物 “活起来”，让经典走出古籍，走进日常，拉近传统文化和当代大众的距离。

做强文旅融合，打造特色文化品牌。文化是旅游的灵魂，旅游是文化的载体。立足本土文化资源，打造好客山东文化 IP，推动文化资源和旅游产业深度融合，避免文旅项目同质化。依托文化资源打造沉浸式体验项目，以文化赋能旅游，以旅游传播文化，实现文化价值和经济价值双赢。

守文化之正，创时代之新。文化 “两创” 非一朝一夕之功，既要守住根脉，又要敢于创新。持续深耕传统文化，推动传统与现代相融，让中华优秀传统文化活在当下、走向未来。
