# 6改革攻坚全国统一大市场

改革是发展的根本动力，建设全国统一大市场，是激发经济活力的关键一招。当前地方保护、市场分割、同质化低效竞争等问题依然存在，制约要素自由流动。苟利国家生死以，岂因祸福避趋之。深化改革攻坚，破除市场壁垒、规范竞争规则、优化营商环境，方能充分释放市场活力。

破除市场壁垒，打通要素流动堵点。地方保护、区域壁垒，阻碍商品、要素自由流通。要清理歧视性政策，破除区域分割，保障各类市场主体公平参与竞争。**临沂商城破除流通壁垒，构建覆盖全国的商贸物流网络，实现商品要素高效流转。**唯有拆除无形壁垒，才能构建畅通循环的统一大市场。

健全竞争规则，引导良性创新竞争。整治内卷式低效竞争，让竞争从拼消耗转向拼创新。完善公平竞争审查制度，统一行业标准，规范招商引资行为。引导企业依靠技术创新、产品提质参与市场竞争，而不是低价内耗。良好的规则，是市场良性发展的压舱石。

优化营商环境，厚植市场主体沃土。市场化、法治化营商环境，是企业生存发展的土壤。持续简政放权，简化审批，落实惠企政策，保护中小企业合法权益。山东持续推进营商环境改革，为企业减负纾困。营商环境持续向好，市场主体才能安心经营、大胆创新。

惟改革者进，惟创新者强。道阻且长，行则将至。坚定不移深化改革，建设高效规范、公平竞争的统一大市场，持续激发市场活力，助力山东经济行稳致远。
