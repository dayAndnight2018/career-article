# 5内需民生投资于人

民生无小事，枝叶总关情。投资于人，就是将发展的落脚点放在人的全面发展上，持续改善民生，释放内需潜力。当前群众仍有增收难、公共服务供给不足、消费顾虑等现实困扰。民为邦本，本固邦宁。持续保障和改善民生，就要拓宽增收渠道、完善公共服务、释放消费活力，让发展成果惠及齐鲁百姓。

拓宽增收渠道，鼓起群众 “钱袋子”。收入是消费的基础，只有收入稳步增长，消费才有底气。健全城乡居民增收机制，拓宽就业岗位，扶持灵活就业，壮大县域富民产业。稳定就业、提高收入，持续缩小城乡收入差距。百姓收入稳步提升，才有能力追求更好生活，为内需增长筑牢根基。

补齐公共服务，消除群众后顾之忧。敢消费，源于完善的社会保障。完善养老、医疗、教育等公共服务，提高基础保障标准，减轻家庭育儿、养老、医疗负担。持续推进公共服务均等化，让城乡群众都能享受到优质公共资源。兜底保障越扎实，群众的后顾之忧越少，消费意愿才能充分释放。

丰富消费场景，激活国内市场新活力。愿消费，需要多元优质的供给。**淄博依托特色文旅 IP，带动餐饮、住宿等产业兴旺，激活县域消费市场，释放内需活力。**挖掘文旅、康养、体育消费潜力，打造城乡消费新场景，落实消费品以旧换新政策。供给提质、场景扩容，才能持续释放内需市场巨大潜力。

治国之道，富民为始。民生温度决定发展厚度。持续投资于人，用心办好民生实事，在改善民生中激活内需，让人民群众共享高质量发展带来的红利。
