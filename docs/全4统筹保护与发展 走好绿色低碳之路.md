# 全4统筹保护与发展 走好绿色低碳之路

绿水青山既是自然财富，也是经济财富。推动绿色低碳转型，统筹降碳、减污、扩绿、增长协同推进，是建设美丽中国的内在要求，也是实现高质量发展的必由之路。

坚持生态优先，守住生态保护红线。生态环境没有替代品，用之不觉，失之难存。严格落实生态保护责任制，持续推进重点区域生态修复。山东扎实推进黄河口国家公园建设、南四湖流域综合治理，守护湿地、林地、河湖生态。严守生态红线，严厉打击破坏生态的违法行为，筑牢区域生态安全屏障。

推动能源转型，构建新型能源体系。实现双碳目标，能源转型是关键。有序发展风电、光伏、氢能等清洁能源，布局源网荷储一体化项目，建设零碳园区。推动高耗能企业节能降碳改造，淘汰落后工艺，推动产业结构、能源结构持续优化。在发展中减排，在转型中提质，避免简单 “运动式减碳”。

倡导绿色生活，凝聚全民绿色共识。生态保护离不开全社会共同参与。政府做好宣传引导，企业落实绿色生产主体责任，公众践行绿色出行、节约水电、垃圾分类等低碳习惯。完善绿色产品供给，引导绿色消费，让绿色理念走进社区、走进家庭，形成人人、事事、时时崇尚生态文明的社会新风尚。

生态兴则文明兴。坚持绿水青山就是金山银山理念，统筹发展和保护，协同推进降碳减污扩绿增长，久久为功、持续发力，绘就天蓝地绿水清的美丽画卷。
