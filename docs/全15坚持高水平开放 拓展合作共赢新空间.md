# 全15坚持高水平开放 拓展合作共赢新空间

开放带来进步，封闭必然落后。高水平对外开放是我国长期坚持的基本国策。在新发展格局下，稳步扩大对外开放，培育外贸新优势，在合作共赢中拓展发展空间。

稳外贸提质效，培育外贸新业态。传统外贸转型升级，大力发展跨境电商、市场采购贸易等新业态。支持外贸企业研发自主品牌，提升产品附加值，从 “卖产品” 向 “树品牌” 转变，增强国际市场竞争力。

用好开放平台，深化经贸交流合作。自贸试验区、综合保税区是开放前沿阵地。依托开放平台，对接国际高标准经贸规则，简化通关流程，优化口岸服务，吸引外资落地，推动内外贸一体化发展，联通国内国际两个市场。

统筹开放与安全，增强风险抵御能力。开放不等于无底线放开，要统筹发展和安全。健全产业链供应链风险预警机制，保障关键产业链自主可控，在扩大开放的同时守住安全底线，实现开放、发展、安全协同。

海纳百川，有容乃大。持续扩大高水平对外开放，积极融入全球分工，在互利共赢中积蓄发展动能，塑造国际合作竞争新优势。
