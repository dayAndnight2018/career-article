# 全10坚持法治引领 筑牢平安建设底线

法治兴则国兴，法治强则国强。法治是治国理政的基本方式，平安是人民幸福安康的基本要求。坚持法治引领，规范执法行为，防范化解各类风险，建设更高水平的平安中国。

规范行政执法，做到严格规范公正文明执法。行政执法直面群众，关乎政府公信力。落实行政执法 “三项制度”，杜绝简单粗暴、一刀切执法。推行柔性执法、说理式执法，落实轻微违法依法不予处罚清单，在坚守法律底线的同时彰显执法温度，平衡监管和服务。

防范化解风险，守住安全稳定底线。树牢底线思维，聚焦安全生产、网络治理、反诈、社会治安等重点领域。常态化排查风险隐患，抓早抓小；严厉打击电信网络诈骗、侵害群众利益的违法犯罪，守住群众财产安全。健全风险预警、应急处置机制，守住不发生重大风险的底线。

深化法治宣传，培育全社会法治信仰。法治建设需要全民参与。持续开展普法宣传，推动法律进乡村、进社区、进企业。引导群众办事依法、遇事找法、解决问题用法、化解矛盾靠法，在全社会营造尊法学法守法用法的浓厚氛围。

以法治护航发展，以平安守护民生。持续推进法治政府建设，守牢安全底线，兼顾力度与温度，为经济社会高质量发展保驾护航。
